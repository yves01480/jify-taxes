# Jify Taxes

> Dedicated Taiwan tax calculation and GUI (Government Uniform Invoice) support for WooCommerce.

Built specifically for WooCommerce stores operating in Taiwan. Handles the 5% VAT and Uniform Invoice (統一發票) requirements that the global tax engine doesn't cover cleanly.

## Key Features

- **Taiwan 5% VAT** — calculated automatically per Taiwan law
- **Inclusive / exclusive pricing** — both calculation models supported
- **GUI number field** (統編) — added to checkout for B2B customers
- **Custom tax label** — display "營業稅" or any localized label in the cart and checkout
- **Tax rounding precision** — matches Taiwan accounting standards
- **Per-item tax after discount** — accurate base-price adjustments (v2.4.0+)

## Installation

1. Upload to `/wp-content/plugins/jify-taxes`.
2. Activate from the **Plugins** screen.
3. Configure under **WooCommerce → Settings → Tax**.
