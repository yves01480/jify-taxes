Dedicated Taiwan tax calculation and GUI (Government Uniform Invoice) support for WooCommerce.

== Description ==

Jify Taxes is built specifically for WooCommerce stores operating in Taiwan. It handles the specific requirements of Taiwan's 5% VAT (Value Added Tax) and Uniform Invoice system.

**Key Features:**

*   **Taiwan 5% VAT**: Automatically calculates the 5% tax rate required by Taiwan law.
*   **Inclusive/Exclusive Calculation**: Supports both tax-inclusive and tax-exclusive pricing models.
*   **GUI Number Field**: Adds a "Unified Business No." (統編) field to the checkout page for B2B customers.
*   **Custom Tax Label**: Allows you to customize the tax label displayed in the cart and checkout (e.g., "營業稅").
*   **Precision Handling**: Improved rounding logic to match Taiwan's tax accounting standards.

== Installation ==

1.  Upload the plugin files to the `/wp-content/plugins/jify-taxes` directory.
2.  Activate the plugin through the 'Plugins' screen in WordPress.
3.  Go to WooCommerce Settings > Tax to configure your rates.
